# 使用研究工作台

[English](../user-guide.md) · [靶点驱动流程](target-workflow.md) · [安装](installation.md) · [案例教程](tutorial.md)

## 准备工作区

按照安装指南启动工作台并启用本地操作。在 **Settings** 选择新研究的工作量、并发、费用上限和 CDES 默认选项。模型与凭证配置见[配置说明](../configuration.md)。

公开案例可以通过[智能体运行器](agent-run.md)恢复。保存的研究保留原配置与费用，新任务记录自己的设置和模型调用。

## 填写靶点与需求

打开 **New research**，填写目标靶点、必需条件和比较偏好，按需补充适应证或研究背景。只填写靶点时，页面会在启动前显示整理出的任务摘要。

必需条件应说明需要满足什么，例如给药途径，或在指定条件下获得的测量值。偏好用于比较合格候选。智能体围绕这些输入形成评价框架，并保留要求与原任务的对应关系。

选择比较对象类型。药物研究使用所选药物库和数据工具；载体等其他对象使用上传的性质与观测。[CSV 指南](csv-input.md)说明身份、数值、单位、条件和来源。

## 选择候选库与证据方式

在 **候选数据库 / 候选库** 中选择范围，也可以上传候选和观测数据。

| 证据方式 | 适用情况 |
|---|---|
| 检索并阅读新证据 | 从新的药物研究问题开始，也可补充已有集合。 |
| 使用已有或上传的证据 | 从明确选定的集合或自有观测形成标准。 |

新检索任务可以直接使用自己的目标与候选库。选择已有集合时，可核对其名称、主题、来源数量和截止时间。

## 选择 CDES 模块

新建任务中的 **CDES 靶点分析** 开关属于本次研究。开启后选择预测集合，查看其已有靶点；流程预览会在筛选排序后增加 CDES 步骤。

CDES 提供结构侧相互作用谱，与已有活性数据和综合评价一起查看。当前模块读取提供的结果，固定所选集合，并报告靶点与候选的对应范围。数据接入和后续部署接口见[组件说明](../components/structure-predictions.md)。

已完成的研究可以在 **CDES 分析** 页关闭或恢复展示，已关联记录保留。Settings 控制新药物任务的默认设置，每项研究也可单独选择。

## 启动与查看进度

使用 **保存草稿** 保留设置，或在输入就绪后开始研究。每个页面保留进度条，显示当前活动、已用时间、最近工作和费用状态。

流程连接任务理解、证据准备、标准展开、提炼、审查、评价准备、候选评估和结果交付。选择 CDES 时加入对应阶段。关键缺项会以具体问题呈现；预算或来源限制会标明需要处理的阶段。

暂停、继续和停止在保存边界执行。服务重启后可从检查点继续。查看费用时，同时关注已记录、估计、部分已知或未知的状态。

## 查看标准形成过程

打开 **标准 → 标准如何形成**，查看起始集合、任务要求、展开与提炼。阶段变化包含新增、修订、合并、撤回和待处理内容。

单条标准展示定义、证据要求、用途、来源与历史。准入要求决定候选资格，评分标准产生排序贡献，参考观察项帮助解释。同一标准也可同时提供准入依据和评分值。

测量定义、单位、汇总方式、比较方法和权重在候选评估前确定。编辑标准会创建新版本，保存的评估继续关联产生它的定义。

## 阅读候选结果

| 分组 | 含义 |
|---|---|
| Eligible | 任务声明的准入要求均有支持。 |
| Evidence incomplete | 已有部分准入支持，其余必需证据仍需补充。 |
| Excluded | 必需条件失败，或完成必需评估后仍无准入支持。 |

执行状态另行标识未完成评估和需要定义、审查的要求。完整规则见[判定说明](decision-language.md)。

候选详情分为 **评分明细、逐项评估与证据、靶点作用谱**。评分明细展示采用值、依据类型、分项得分、权重与贡献，并给出排名所用的覆盖率。合格候选低于所设覆盖门槛时，保留资格并显示未排名原因。

连续评分在合格且有值的候选中比较。总分平均已有的加权贡献，覆盖率依据适用的评分框架计算。CDES 作用谱则按各自单位展示相互作用分数与已有活性数据。

搜索和筛选覆盖所选分组的完整候选，再进行分页。通过已保存评估选择器查看相应版本。

## 追溯来源

候选与标准的链接会把研究上下文带入 **证据** 页面。发现按文献或来源记录分组，展开后可查看数值、实验条件、原文位置及使用它的标准。

在 **CDES 分析** 中点击预测，查看原始行和蛋白输入；点击 **查看观测**，进入对应候选与靶点标准的已有来源。预测库和研究候选库分别统计，并展示对应关系。

## 导出与继续研究

**导出全部候选** 下载所选评估的完整结果。CDES 页的 **下载完整数据包** 导出关联结果与来源文件，保留解释数值所需的评估身份。

使用 **按此设置新建研究** 沿用输入并开始新的标准集。下一项研究可以更换靶点、需求、候选库、证据方式和模块选择。[案例教程](tutorial.md)使用已公开记录演示完整查看路径。
