# 使用研究工作台

[English](../user-guide.md) · [安装](installation.md) · [完整案例](tutorial.md)

## 准备工作区

按安装指南使用 `-AllowOperations` 启动现代工作台，在本地浏览器操作任务、上传、设置和运行控制。使用期间保持服务终端运行。新工作区初始为空；恢复已发布案例及其输入请使用[智能体一键运行](agent-run.md)。

首次研究前打开 **Settings**，选择工作强度、并发与预算。模型、密钥和可选预测环境通过 TOML 配置，详见[配置说明](../configuration.md)。若没有可用价格，费用会保持未知；应查看费用状态，不能把未知当成零消耗。

## 创建任务

选择 **New research**，写清候选应当实现什么、适用于什么条件。设置研究对象、必需靶点或性质、约束和候选范围。口服药物研究可以要求口服给药记录，并要求指定靶点有直接观测；载体研究则需要自己的性质定义和实验条件。

硬条件、偏好和参考用途分别表达。硬条件明确失败时可以淘汰候选；偏好比较合格候选的相对表现；参考观察帮助理解结果而不增加排名权重。系统保存原始输入及整理后的研究范围。

选择候选库和证据输入。仅使用已有证据的任务，需要保存集合或上传测量；新工作区应先提供数据。选择检索模式会访问配置的来源。[CSV 指南](csv-input.md)说明身份、测量、单位、依据和预览检查。可以先保存草稿，或在输入完整后启动。

## 观察进度与控制运行

各页保留进度条，展示阶段、当前工作、最近活动、时间和已记录费用。一个阶段可能包含很多批次，当前批次进度不代表整个研究的剩余时间。

流程连接任务理解、证据准备、提出标准、审查提炼、解决争议、固定方案、评估候选和发布结果。无法推断的关键缺项需要补充；预算或依赖不足时显示具体未完成阶段。

**Pause / Continue / Stop** 在支持的检查点生效，关闭终端前先看实际状态。服务重启后，未完成的工作流可以从保存工作继续。完成的评估保留为结果快照，后续工作通过新任务或有记录的重新评估开展。

## 理解评估标准的演化

在 **Criteria** 查看数量轨迹和最终用途。工作项包括尚未形成可执行标准的提议，所以工作项、注册标准和启用决策规则数量可能不同。

打开阶段查看新增、修订、合并、移除及待处理内容；打开标准查看定义、规则、来源和历史。合并应保留父项及理由。重点检查最终用途：强制要求、排序标准、参考观察项和未纳入本次评估的内容对结果的作用不同。

评估前固定测量方式、单位、汇总、允许的依据和决策方法。修改标准形成新版本；使用重新评估入口时，应查看影响范围和新结果。旧快照继续绑定原来的规则。

## 理解候选分区和评分

[统一定义](decision-language.md)区分资格、证据程度、执行状态与排名。

| 分区或状态 | 含义 |
|---|---|
| 合格 | 满足启用硬条件与必需直接证据；是否排名还取决于偏好证据覆盖 |
| 准入证据不完整 | 一部分准入要求已有依据，显示其余要求与具体缺口 |
| 已排除 | 强制条件失败，或必需评估完成后均无准入依据 |
| 评估未完成 | 必需评估未完成、工具失败或评估记录不可用；独立于科学结论 |
| 前序失败后跳过 | 逐层模式因前面硬失败而省略该项后续评估 |

没有有效硬条件时，筛选尚未就绪。异常淘汰率触发诊断，不会自动把硬条件改成偏好。预测不单独满足本流程的直接证据要求。

点击 **Score** 查看采用值、依据类型、比较分、权重和最终贡献。连续偏好在合格且有值的候选间比较，并列共享平均位置；阈值偏好按冻结的判断方式计算。分数分母与直接证据覆盖分母可能不同，缺值和预测辅助值分别显示。

搜索和筛选先作用于完整分区，再分页。使用保存评估选择器切换版本，分数需要结合该版本的规则和比较集合解释。

## 从结论回查来源

从候选或标准打开 **Evidence**，页面保留所选候选、标准及评估范围。文献先按来源归组，显示研究对象与关联标准，再展开具体发现，查看数值、条件、依据类型及原文位置。完全重复的发现可以继续展开原始记录。

证据集合显示名称、简介、主题、来源数和截止时间。修改这些展示信息不会改写科研证据。一个来源可以支持多项标准，但同一计分性质的重复支持不会因此成为重复贡献。

## 导出与继续研究

**Export all candidates** 导出所选评估的完整候选范围，包括主榜以外的状态。保存榜单时保留对应任务、规则版本、证据范围与快照身份。[已有案例](../../examples/oral-multitarget/)提供完整 JSON/CSV 示例。

**New study with this setup** 复用任务设置和保存证据，同时从新的标准集开始。通过支持的上传入口补充材料，或以新版本修改任务范围。新的模型运行可能产生不同的标准轨迹，应根据它自己的实际结果判断。

[口服多靶点教程](tutorial.md)提供从配置到导出的完整截图、数值与来源核对过程。
