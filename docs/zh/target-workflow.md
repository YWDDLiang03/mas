# 以靶点和需求驱动药物筛选

[English](../target-workflow.md) · [使用指南](user-guide.md)

用户提供靶点、研究需求和候选库。智能体根据证据形成评价标准，按任务要求筛选候选，再比较合格药物。适应证、给药要求和候选范围都来自当前任务。

主流程为：**靶点与需求 → 标准生成与审查 → 筛选排序 → 结果与依据**。开启 CDES 后，在筛选排序之后增加靶点相互作用分析。

## 新建任务

1. 填写靶点与必需条件或偏好。补充研究背景可以帮助智能体理解证据；只填写靶点时，页面会先显示整理出的任务摘要。
2. 选择候选数据库或候选库。新药物任务可以直接检索新证据，也可以选择已有证据集合。上传数据的研究沿用其观测数据。
3. 按需开启 CDES，并选择预测集合。页面同时展示本次流程及集合覆盖的靶点。
4. 启动研究。三智能体完成标准提议、批评、修订与裁决后，系统按确定的标准进行候选评估。

## CDES 开关

Settings 中的开关控制**新药物研究的默认设置**，初始为关闭。新建任务时可以单独选择。已经关联预测的案例，也可以在 CDES 分析页关闭或恢复展示，原记录继续保留。

CDES 回答候选结构与目标蛋白之间的相互作用问题；智能体负责评价标准的形成与证据整合。当前模块使用已提供的结果，并保留后续连接部署模型的接口。

预测集合会固定版本，并按新任务的靶点与候选身份关联。新任务的观测值、单位、资格和排名来自自己的评估记录。集合未覆盖的靶点或候选会说明具体缺项，基础筛选结果仍可查看。

## 本次流程调整

- 新证据检索模式可以从新任务开始，无需选择过去的案例。
- 给药相关研究维度依据任务选择，其他给药要求保留原意并形成对应条件。
- CDES 开启时才出现对应的流程阶段，运行状态与关联数量单独记录。
- 工作台把 CDES 标为可选模块，标准、候选、证据和综合排名继续作为主流程页面。

原口服多靶点案例的数字与排名保持其保存结果。其他任务使用自己的靶点、需求和标准数量。
