# TRIAGE 怎样形成评价框架

[English](../design.md) · [文档导航](README.md) · [组件参考](../components/README.md)

## 通用流程与具体任务

每项研究提供目标、候选总体和来源证据，并明确必需条件与观测。任务决定研究什么；通用流程组织提议、审查、评价和解释；领域适配器提供适用于研究对象的身份、性质定义与工具。

新研究从空标准集开始，保留任务明确提出的要求，再依据所选证据形成其他标准。已有事实可以复用，早先任务的标准和分数则保留在各自研究中。

## 为什么先展开，再提炼

提议阶段从多个相关维度考虑性质和测量方式，使有用的方向进入讨论，也暴露重复、含糊或依据不足的提议。随后通过审查明确哪些内容能用于有意义的比较。

| 角色 | 职责 | 反馈方式 |
|---|---|---|
| Proposer，提议者 | 指定性质、适用条件、证据和评价用途 | 根据具体意见修订或撤回提议 |
| Critic，审查者 | 检查来源支持、相关性、测量含义与适用性 | 将意见关联到提议及支持材料 |
| Adjudicator，裁决者 | 处理仍待解决的解释，比较相关提议 | 合并、整合或保留区别，更新后的标准继续审查 |

提炼澄清定义、移除支持不足的提议、合并兼容描述。实验条件或决策含义不同的内容可以继续区分。标准及其关系保存在历史中，Criteria 页面据此展示最终框架的形成过程。

停止由预设轮数及连续无变化条件控制，达到轮数上限时记录这一实际原因。标准数量目标用于安排工作，最终数量由独立而有用的评价内容决定。

实现入口：[提议与提炼](../../src/mas/core/derivation_stages.py)、[轮次控制](../../src/mas/core/derivation_run.py)、[标准历史](../../src/mas/core/pool.py)、[裁决](../../src/mas/core/adjudication.py)。

## 准入与评分分别承担什么作用

准入要求包括必须满足的条件和必须具备的直接观测。同一标准可以要求某项观测齐备，并使用其数值评分。解释性观察提供背景信息，不增加评分权重。

适用条件明确失败时归入 Excluded。其余候选中，必需依据齐全为 Eligible，部分依据已有但仍有缺项为 Evidence incomplete；必需评估完成后所有准入要求均无依据时为 Excluded。评估未完成和工具不可用保留各自的执行状态。[判定说明](decision-language.md)给出完整规则与例子。

评分使用已确定的比较方式和权重，连续数值在合格且有值的候选中比较。允许的预测可以参与得分；直接证据覆盖另行计算接受的测量、整理数据和计算值。保存的覆盖门槛决定合格候选能否取得名次。

实现入口：[评估](../components/assessment-and-qualification.md)、[分类](../../src/mas/core/selection.py)、[排名](../components/ranking-and-explanations.md)。

## 保留观测的科学含义

实测、数据库整理、结构计算和模型预测分别记录。标准声明接受的单位、条件和汇总方式；解释汇总值时需要同时查看测量端点和实验信息。同一实验也可能被多个数据库收录。

Evidence 页面按来源组织发现，并链接使用这些发现的标准与候选。候选详情区分准入判断、评分贡献、预测和缺失信息。[证据组件](../components/evidence-and-reading.md)及[CSV 导入](csv-input.md)说明具体内容。

## 更换研究问题

更换目标和要求，提供相应候选与观测，再选择适用工具。例如合成的载体示例可以要求测得的粒径范围与细胞活力，再比较递送效率。通用判定函数使用这些配置；药物靶点和案例数量属于具体任务。
