# MAS v1.0.0

The first formal release packages the research workbench, portable first-use setup, current component documentation and two retained oral multi-target studies.

## Included

- Natural-language tasks, candidate and measurement CSV import, and selectable existing-evidence or retrieval workflows.
- Criterion proposals, review, refinement, merge history and frozen evaluation rules.
- Hard-condition qualification, explicit missing/unresolved/skipped states, qualified-candidate ranking and per-preference score explanations.
- Persistent progress and workflow control, source-grouped evidence, versioned results and complete candidate export.
- English-default UI and README, Chinese README and installation/usage/CSV/tutorial/comparison guides.
- Twelve component chapters with implementation references, design rationale and examples; a C1–C20 implementation status map.
- A complete tutorial for the latest saved run and a descriptive comparison against the original eleven CQAs.
- The 34-slide system/case presentation with speaker notes.

## First-use fixes

The Windows launcher now supports explicit empty-workspace initialization and resolves repository-relative paths correctly when launched from another directory. Model/configuration examples no longer require private paths from the development machine. The Python and client versions are both 1.0.0; new run bindings obtain the service version from the package.

The former audit-only publication guard for private recovery reports also covers the new `docs` and `examples` destinations. The published CQA table is a separately authorized, factual post-hoc summary, not a raw evaluator report or a derivation input.

An obsolete upload-test expectation was corrected to match existing semantics: usable numeric evidence without a qualitative interpretation method is unresolved, while absent evidence remains missing. The assessor and saved research results were not altered by that test correction.

The Linux release checks also exposed a timing-dependent batching assertion: generated criterion IDs do not guarantee insertion order within one millisecond. The regression now checks exact once-only coverage and the same batch sizes, without imposing an unsupported order. No derivation behavior changed.

## Retained research

The latest study contains 3,177 candidates, 18 core rules and 13 context observations. Surufatinib passes its enabled oral condition, has direct evidence for five required targets and ranks first among ten qualified candidates, with score 0.7592592593 and direct preference coverage 10/17. Another 3,167 candidates remain pending evidence. The comprehensive study, where Surufatinib ranks fourth under a different rule set, remains separately available.

All 28 manifest-bound files across the two final export packages keep their original bytes and SHA-256 values. The original PDFs and private operational database are not included. A fresh checkout can inspect the published example, but needs its own inputs and credentials for new research.

The original eleven-CQA comparison identifies two same-named endpoints with changed decisions, three related/unresolved rows and six absent endpoints. No complete original pass/fail gate equivalence is established. This release does not claim a new blind recovery measurement or reproduction of the original eleven-condition screen.

## Validation and scope

Local validation used Windows, Python 3.14.2 and Node.js 24.13.0. It included a fresh temporary source installation, new virtual environment, dependency installation, frontend build, launch from outside the checkout, HTTP delivery of the actual client assets and an empty scientific store. No paid model or retrieval call was made during release preparation.

The final offline suite passed **677 tests**, with **15 live tests deselected**. The obsolete assertion described above was corrected before this final run; the affected upload/preference/context checks also passed all 16 selected tests. Launch/configuration/upload checks, the clean-install integration checks, the production frontend build and the real API read/export check passed. The publication checker verified 507 local links, coordinated versions, 28 original result-file hashes, comparison inputs and the presentation hash. [Source checks](../../.github/workflows/ci.yml) run the offline suite and client build for future changes; see the GitHub run for its actual result.

The optional predictor environment and live provider paths were not revalidated for this publication. General agent planning, a persistent open-question service, scoped memory and a strategy-promotion archive remain partial or planned as described in the [architecture](../architecture.md). The repository does not currently include a selected software license grant.
