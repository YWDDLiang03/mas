# 从研究者角度看工作台

本轮依据实际的新建研究、运行中切页、证据阅读和结果查看整理。界面继续使用浅蓝主色；信息层级优先回答“现在做到哪里、结论来自哪里、下一步能做什么”。

## 已落实的改进

| 使用时遇到的问题 | 当前处理 |
| --- | --- |
| 新建研究的准备期间，旧任务正文容易与新任务进度混在一起 | 新研究显示独立的准备状态；创建完成后进入自己的概览。其他研究的进度有独立入口。 |
| 想按原案例重跑时，需要手工重新填写，容易漏掉参考候选等设置 | 增加“按此设置新建研究”，保留目标、证据与候选库等选择，明确标准仍从零生成。 |
| 生成中的提议持续增加，顶部数字却仍是上一阶段的数量 | 明确标为“上一完成阶段”，同时保留当前主题的真实批次和阶段前后变化。 |
| 完成后最显眼的操作是重新评估，找结果反而费力 | “查看已保存结果”成为主要操作，重新评估放入次级操作。 |
| 长文献详情需要反复滚动，难找引用原文和用途 | 增加“发现、原文、关联用途”快捷入口，原文入口直接定位引用段落。 |
| 来源标签和章节标题不容易读 | 用完整、简明的界面文字表示来源类别与核验状态，分开显示章节路径与段落标题，并增大阅读字号。 |
| 窄窗口内完成状态占据过多空间 | 收紧完成后的进度区域，同时保留八个阶段。 |
| 标准总数容易与真正影响决策的数量混淆 | 分开显示核心标准、仅供参考的标准和尚未启用项，并列明硬条件与排序偏好。 |
| 候选详情的来源数字混用了旧计数口径，长说明需要横向滚动 | 按逐项评估的实际依据显示实测、推导与预测数量；判定说明点击展开，保留数值、单位和证据入口。 |
| 标准改版时，看不出证据类型和判断依据具体改了什么 | 展示证据类型、依据与取值路线的前后差异，属性与评估规则分开；完整记录继续可查。 |
| 一段研究动机连接了很多候选，容易被误读为每个候选都有测量 | 每条关联标明是标准依据、实际取值、反证或未使用的证据；通过标准产生的关联单独说明。 |

## 最值得继续改进的三个地方

**证据按文献组织。** 同一篇文献中的多个发现目前仍可能连续占据多张卡片。可以先显示文献名称、研究对象和被哪些标准使用，再展开具体发现；保留不同实验条件与原文位置，减少重复阅读。

**候选并排比较。** 在合格榜勾选两到三个候选后，将硬条件、必需观测、主要偏好与缺失证据并排展示。使用者能直接理解排名差异，也更容易发现“数值接近、证据完整度不同”的情况。

**证据集合有清楚的名称和简介。** 历史集合目前常以很长、相近的研究目标命名。增加可读名称、来源数量、截止时间和适用主题，选择已有证据时会更有把握。

这些建议服务于实际阅读和判断，不改变筛选条件或评分结果。证据不足时继续展示缺项和原因。
