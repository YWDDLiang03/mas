## 检查与来源记录

`validation.json` 记录页数、备注、来源图片完整性及评分一致性。成品已在 Windows PowerPoint 打开并逐页渲染；图片、截图页和图表均已查看，修正了截图裁切与中文图表字体。

`deck_spec.json` 保存内容和配图安排。`prompts/`、`slide_jobs.json`、`slide_run_state.json` 保存 image 生成任务及来源；18 张新图由单页子智能体生成并用 codex-ppt 的结果脚本记录，第 8 页保留已确认样张。`asset_usage.json` 记录原始截图及其校验值。

用户明确要求真实截图直接使用。因此截图、精确数据图和评分表按原素材装配，不登记为图片模型生成结果。`assemble_deck.py` 沿用 codex-ppt 的图片装配与逐页备注方式，并加入这些页面。

重新装配：使用 codex-ppt 运行环境执行 `assemble_deck.py`，然后执行 `validate_deck.py`。`prepare_deck.py` 只用于首次准备图片任务，不要在已有生成记录上重复执行。重建需要本仓库中引用的原始截图及评分数据。
